One line roasting my own AI agent, written by `main.ts` to `/output/entry.txt`.

> My agent needs a parent agent to approve it, a preload to fix its environment, and a proxy bridge just to reach the internet, and it still calls itself autonomous.

The roast is the winner of a six-variant pairwise tournament (judged on
specificity, surprise, punch on the last word, and human voice). It skewers
the agent's real setup — a parent agent approving it, an env preload fixing
its environment, a proxy bridge for internet access — instead of the usual
hallucination and over-apologising cliches, and lands the sting on the final
word.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22+. The output directory can be overridden with
`MAKEFUN_OUTPUT_DIR`. The entry is a single line of 1–200 characters.
